# Spec Delta

## Purpose
确保交易面板依据交易所返回的信息报告订单与撤单状态，避免将订单被接受误认为已经成交，并保留无法确认的信息。

## ADDED Requirements

### Requirement: 如实报告订单结果
系统 SHALL 仅在有明确成交数量证据时报告成交数量或完全成交，并区分提交失败和已接受。

#### Scenario: 已接受但未提供成交量
- **WHEN** 交易所接受订单但未返回成交数量
- **THEN** 系统报告订单待处理，成交数量未知

#### Scenario: 查询到部分成交
- **WHEN** 订单查询返回部分撮合数量
- **THEN** 系统报告该数量且不报告全部成交

#### Scenario: 拒绝或异常响应
- **WHEN** 交易所拒绝订单或响应无法确认接受
- **THEN** 系统不报告提交成功

### Requirement: 核实撤单结果
系统 SHALL 根据交易所撤单结果报告是否确认撤单。

#### Scenario: 撤单被拒绝
- **WHEN** 返回未撤销的订单及原因
- **THEN** 系统报告撤单失败和原因
