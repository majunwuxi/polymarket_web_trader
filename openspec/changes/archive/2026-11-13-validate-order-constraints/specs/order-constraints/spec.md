# Spec Delta

## Purpose
确保交易面板按订单簿提供的最新市场规则校验限价和份额，避免提交无效订单或在用户不知情的情况下改变其价格及数量。

## ADDED Requirements

### Requirement: 校验市场价格与份额
系统 SHALL 在提交或模拟订单之前使用目标资产的当前订单簿校验有限数值、价格增量、价格边界、最小订单量及两位小数份额精度，不得静默改变提交的价格或数量。

#### Scenario: 有效价格和数量
- **WHEN** 价格符合订单簿增量和边界，份额达到最小值并符合精度
- **THEN** 系统保留输入值并继续处理订单

#### Scenario: 不符合增量或数量不足
- **WHEN** 输入不符合价格增量、价格边界、最小份额或数量精度
- **THEN** 系统拒绝订单并说明约束，不提交订单

#### Scenario: 规则不可用
- **WHEN** 订单簿或其约束缺失或无效
- **THEN** 系统拒绝订单并提示无法验证规则

### Requirement: 计算数量时向下取整
系统 SHALL 将由金额或持仓比例推导的份额向下取整至两位小数，买入确认界面展示提交的份额。

#### Scenario: 金额计算的买入份额
- **WHEN** 金额除以价格得到多于两位小数的份额
- **THEN** 界面在确认前向下取整并提交展示的份额

#### Scenario: 比例计算的卖出份额
- **WHEN** 持仓乘以卖出比例得到多于两位小数的份额
- **THEN** 系统向下取整，且不得超过相应持仓或比例
