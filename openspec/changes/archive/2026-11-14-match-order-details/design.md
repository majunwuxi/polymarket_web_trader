# Design

## Context
单场订单接口已按 game_id 分页；组合腿关联比赛，组合接口尚无该筛选。

## Goals / Non-Goals
只读显示关联订单及其真实状态，不触发对账、下注或更改订单。

## Decisions
组合接口用 EXISTS 过滤赛事，保留原有游标分页及 confirmed 筛选；详情页并行读取单场与已确认组合，各自分页及错误提示，并以请求代次防止切换赛事时显示旧结果。组合仅显示本场对应的腿，并明确组合报价不等于单场成交价。

## Risks / Trade-offs
接口失败须标注加载失败而非空记录；执行中、未知等单场状态不得误称成交。
