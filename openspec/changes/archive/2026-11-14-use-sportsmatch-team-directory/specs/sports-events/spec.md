# Spec Delta

## ADDED Requirements

### Requirement: 球队目录安全展示
系统 SHALL 使用用户指定球队资料的固定版本，为英文名称可唯一匹配的足球和 NBA 球队提供中文名及队徽回退，不覆盖管理员确认的中文名或改变交易匹配依据。

#### Scenario: 唯一匹配
- **WHEN** 来源球队的完整名称在对应运动目录中唯一匹配
- **THEN** 系统可展示目录中文名和缺失或通用占位队徽的目录队徽，并标注资料来源

#### Scenario: 名称冲突或资料缺失
- **WHEN** 目录没有唯一匹配或信息缺失
- **THEN** 系统保留来源名称和已有队徽，不猜测球队身份

#### Scenario: 人工维护中文名
- **WHEN** 管理员已维护经过确认的中文名
- **THEN** 页面优先显示该中文名且目录不会改写数据库
