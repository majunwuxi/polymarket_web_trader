# Spec Delta

## ADDED Requirements

### Requirement: 钱包状态安全诊断
钱包状态接口和页面 SHALL 显示可识别的安全诊断，独立表示地区检查结果，不得暴露密钥、完整 RPC 地址或上游异常原文。

#### Scenario: 后续检查失败
- **WHEN** 地区检查通过但钱包身份、RPC 或余额查询失败
- **THEN** 页面展示地区检查通过和固定的对应诊断，不将失败误判为地区限制

#### Scenario: 凭据缺失
- **WHEN** 钱包缺少有效凭据引用
- **THEN** 页面提示检查凭据引用，余额保持未知

#### Scenario: 意外错误含秘密
- **WHEN** 异常包含私钥、RPC 地址或其他敏感信息
- **THEN** 接口只返回固定通用错误，不返回异常原文

#### Scenario: 未检查能力
- **WHEN** 页面未实际检查授权或 Builder 能力
- **THEN** 页面明确标示未检查，不声称已验证
