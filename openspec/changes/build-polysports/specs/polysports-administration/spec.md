# Spec Delta

## Purpose
为个人赛事交易系统提供可管理、安全访问、可追踪的运行环境和数据导出能力，并支持独立安装、维护与备份。

## ADDED Requirements

### Requirement: 管理与导出
系统 SHALL 提供单一管理员登录、HTTPS 访问、集中配置、同步日志、运行状态、历史统计以及 Excel 和 CSV 导出；密钥不得进入 Git 仓库或日志。

#### Scenario: 导出历史数据
- **WHEN** 管理员选择历史数据并请求 Excel 或 CSV 导出
- **THEN** 系统导出所选真实记录和明确字段

#### Scenario: 外部服务失败
- **WHEN** 第三方 API 不可用或缺少必要权限
- **THEN** 系统报告失败或不可用，不使用虚构数据冒充真实数据

### Requirement: 独立部署
系统 SHALL 提供 PostgreSQL 数据库迁移、自动化测试、Nginx、systemd、维护和备份说明，且不依赖原有 Dashboard 运行。

#### Scenario: 独立安装
- **WHEN** 管理员按部署说明安装并配置所需凭证
- **THEN** 可独立启动应用和后台任务，并执行迁移与备份恢复流程

### Requirement: 管理员身份与会话保护
系统 SHALL 仅通过本机管理命令初始化唯一管理员；密码安全哈希保存，认证会话支持过期及撤销，所有写请求校验同源和会话绑定 CSRF，并在共享数据库中限制登录尝试。

#### Scenario: 未认证访问业务接口
- **WHEN** 未登录的访问者请求业务接口
- **THEN** 系统返回认证错误，不暴露业务信息

#### Scenario: 跨站请求
- **WHEN** 写请求缺少有效同源 Origin 或匹配 CSRF 令牌
- **THEN** 系统拒绝执行，不修改认证状态或业务数据

#### Scenario: 跨实例登录限流
- **WHEN** 登录失败次数达到限制并通过另一个应用实例继续尝试
- **THEN** 系统仍拒绝请求并返回等待时间

#### Scenario: 会话失效
- **WHEN** 管理员退出或会话过期
- **THEN** 该会话不能继续访问受保护接口

### Requirement: 历史统计及安全导出
系统 SHALL 按相同筛选条件返回历史记录、统计与全量 CSV/XLSX 导出；时间范围为有时区的左闭右开区间，文件时间标注 UTC+8。收益在缺少可核验证据时 MUST 为 null，不能把订单接受、执行中或未知状态视为成交。

#### Scenario: 公式注入与大整数
- **WHEN** 外部文本以公式字符或前置空白加公式字符开头，或者包含大整数标识
- **THEN** 导出将文本安全转义并保留标识原文，不将其转换为数值或公式

#### Scenario: 多页筛选与导出
- **WHEN** 筛选结果超过单个页面
- **THEN** CSV 与 XLSX 包含同一筛选条件的全部记录，不能只导出当前页面

#### Scenario: 收益证据不足
- **WHEN** 缺少完整费用、结算或成本证据
- **THEN** 已实现收益保持未知，真实成交统计仅采用明确的上游成交证据
