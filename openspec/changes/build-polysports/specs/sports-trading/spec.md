# Spec Delta

## Purpose
将赛事与 Polymarket 市场准确关联，支持由用户确认的真实单场交易和组合询价执行，并对交易结果进行持久核对。

## ADDED Requirements

### Requirement: 单场与组合下单
系统 SHALL 支持钱包签名、赛事交易入口、单场订单和 Polymarket Combo RFQ 组合订单，在用户确认价格和金额后执行，并将关联赛事纳入关注。

#### Scenario: 单场下单
- **WHEN** 用户确认一个匹配的赛事市场及有效订单
- **THEN** 系统按官方 CLOB 接口签名提交并保存订单状态和关注赛事

#### Scenario: 组合询价
- **WHEN** 用户选择可组合赛事并请求报价
- **THEN** 系统使用官方 Combo RFQ 流程获取真实报价，确认后接受报价并跟踪执行状态

#### Scenario: 外部请求结果未知
- **WHEN** 订单或报价接受请求超时且结果无法确认
- **THEN** 系统记录未知状态并进行对账，不自动重复提交

### Requirement: 验证赛事市场对应关系
系统 SHALL 验证赛事与交易市场的对应关系；存在歧义时必须要求管理员确认，不能自动把订单关联到猜测的赛事。

#### Scenario: 多个候选市场
- **WHEN** 市场与多个赛事存在匹配可能
- **THEN** 系统要求人工确认后才能交易
