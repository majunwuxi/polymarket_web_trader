# Spec Delta

## ADDED Requirements

### Requirement: 从交易记录发起实时平仓
交易记录 SHALL 提供对已核实单场持仓和组合持仓的平仓入口，核实原钱包、持仓身份和实时可卖数量，提供明确价格限制与真实资金确认；MUST 保留操作意图及未知结果，不自动重发或误称成交。

#### Scenario: 可用单场持仓
- **WHEN** 用户选择有可卖份额的单场持仓
- **THEN** 系统展示真实可卖份额及实时退出条件并在用户确认后发送卖出

#### Scenario: 组合持仓
- **WHEN** 用户选择已确认组合且持仓身份及余额可核实
- **THEN** 系统按原组合腿请求卖出报价并在明确确认后提交

#### Scenario: 持仓不可核实或结果未知
- **WHEN** 资产、余额无法可靠确认或提交结果不明确
- **THEN** 系统不猜测、不自动重发，并展示真实状态供核查
