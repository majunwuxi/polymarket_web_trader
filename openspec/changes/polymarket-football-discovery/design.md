# Design

## Context
Polymarket Gamma 按足球标签提供比赛事件、球队、开始时间和不同市场类型。一次比赛可有多个事件；必须按 `gameId` 等经过验证的标识聚合，不得把半场、让分或准确比分当作胜平负。

## Goals / Non-Goals
优先展示未来 36 小时真实胜平负赛事；保留既有 NBA 和历史。API-Football 仅作按需匹配及后续赛果来源，不承诺免费套餐可用于当前赛季。

## Decisions
先独立实现和测试发现适配器，再处理迁移、调度及接口。Gamma 事件分页不可截断，使用来源明确的主客队和比赛开赛时间，本地过滤窗口。下单前核实 Polymarket 赛事和市场身份，但不要求 API-Football 绑定。仅当上游明确接受订单并能确认订单身份后，持久化赛果绑定任务；超时、拒绝和结果未知不得触发绑定，未知订单先对账。接受订单不等于成交。持久化时维持赛事来源身份和已确认的外部绑定，禁止猜测或覆盖历史。绑定采用候选证据及人工确认。未绑定或来源失败时不能虚构比分或完赛；既有交易保护不得削弱。

## Risks / Trade-offs
Polymarket 仅覆盖其开设市场的赛事；来源字段缺失或矛盾时跳过并记录。来源分页不完整时同步失败。API-Football 免费权限可能无法绑定当前赛事，必须明确报告。真实交易和有密钥联调不在自动化测试中执行。
