# Spec Delta

## ADDED Requirements

### Requirement: 指定足球赛事范围
足球赛事列表 SHALL 仅包含用户指定的英超、英冠、德甲、德乙、意甲、西甲、法甲、法乙、荷甲、荷乙、葡超、瑞超、挪超、芬超、欧冠、欧罗巴、欧协联、亚冠精英、世界杯、世预赛、欧洲杯、欧国联和亚洲杯中来源标识可确认的比赛。

#### Scenario: 非指定赛事
- **WHEN** Polymarket 足球胜平负赛事属于其他赛事或无法确认所属赛事
- **THEN** 系统不将其显示在未来足球赛事列表，保留原有历史数据

#### Scenario: 标签歧义
- **WHEN** 上游赛事标签不完整或同时指向多个指定赛事
- **THEN** 系统不猜测赛事归属

#### Scenario: 完整同步和失败
- **WHEN** 来源同步完整成功或中途失败
- **THEN** 仅完整成功时更新范围内可见赛事，失败保留上一次完整同步结果
